I definitely need to do a few more "trace" exercises to make sure I don't get lost in the nested loops when the logic gets more complex.

How GitHub Works (My Understanding)

For me, GitHub is like a giant "save button" in the cloud for my code, it also is like a social network, for example like Facebook, but designed for programmers. . It uses a system called Git that keeps track of every single change I make. I create a "Repository" (which is basically my project folder), and every time I finish a part of my assignment, I do a "Commit" to save it and then a "Push" to upload it to the web. This way, my work is safe, and I can show my progress to my teacher.
